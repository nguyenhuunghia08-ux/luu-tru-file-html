Lưu ý kỹ thuật (file://)

Bạn đang mở file HTML trực tiếp từ máy tính. Trình duyệt có thể chặn phát video YouTube do chính sách bảo mật (CORS/Origin).

Cách khắc phục:

  • Tải file HTML này lên các dịch vụ hosting miễn phí (như GitHub Pages, Netlify, Vercel) để chạy dưới dạng đường dẫn web https:// bảo mật.
  • Hoặc mở bằng một máy chủ ảo local (Ví dụ: extension Live Server trên VS Code, hoặc chạy lệnh python -m http.server 8000).
